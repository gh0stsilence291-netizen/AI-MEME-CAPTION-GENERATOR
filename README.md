# AI Meme Caption Generator

Simple but fun project that generates funny meme captions based on a short description of the image/situation.

Uses template-based + keyword smart generation (lightweight, no GPU needed). Perfect for portfolio to show creativity.

## Features
- Describe any situation or image
- Get multiple funny caption options (English + Hinglish mix)
- Instant results
- Easy to extend with more templates

## How to Run (Google Colab)

1. Open Google Colab
2. Copy the code from ``meme_caption_generator.py` + **`AI_Meme_Caption_Generator.ipynb`**`
3. Run it
4. Describe the meme situation → get captions

## Installation (Local)

```bash
pip install -r requirements.txt
python `meme_caption_generator.py` + **`AI_Meme_Caption_Generator.ipynb`**
```

## Tech Stack
- Pure Python (no heavy ML models for speed & simplicity)
- Keyword matching + templates
- Easy to upgrade later with BLIP / GPT-style models
